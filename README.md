# Polza Agency: тестовое «Вайбкодер-аутричер»

Конвейер для B2B-аутрича: сбор базы с официальных сайтов, персонализация фактами с сайта, цепочка из 3 писем.

## Файлы

| Файл | Задача | Назначение |
|---|---|---|
| `collect_base.py` | 1 | Собирает email с сайтов из списка доменов; только адреса на домене компании; отбрасывает служебные ящики (hr, pr, support, abuse...); проверяет MX |
| `seeds.csv`, `seeds_extra.csv` | 1 | Стартовые списки доменов российских B2B-компаний (87 + 25) |
| `enrich_names.py` | 1 | Ищет на официальных сайтах ФИО и должность ЛПР (коммерческий директор, продажи, маркетинг, генеральный директор) для колонки «Имя контакта»; всегда указывает URL источника |
| `personalize.py` | 2, 4 | Персонализация. Без ключа API: свежая новость или описание прямо из HTML. С ключом `ANTHROPIC_API_KEY`: факт пишет LLM, но обязан дать цитату, которая реально есть на сайте |
| `task4_input.csv`, `task4_result.csv` | 4 | 15 компаний из таблицы заказчика (как есть) и результат прогона `personalize.py` |
| `base_final.csv` | 1, 2 | Итоговая база: 58 компаний (сегмент, проверенный факт, evidence, источник, персонализация для письма, запасной заход по сегменту) |
| `email_sequence.md` | 3 | Цепочка из 3 писем с переменными {{имя}}, {{компания}}, {{сегмент}}, {{персонализация}} (то же на листе таблицы) |
| `vibecode_stack.txt` | 5 | Мой стек, написан вручную |

## Запуск

```
pip install requests beautifulsoup4 dnspython
python collect_base.py seeds.csv base.csv
python personalize.py base.csv result.csv          # режим без LLM, ключ не нужен
python personalize.py task4_input.csv task4.csv    # задача 4
python enrich_names.py base_final.csv base_names.csv  # имена ЛПР с сайтов компаний
```

Выход `collect_base.py` подходит на вход `personalize.py`.

## Защита от выдумок и «перепутанных» данных

- Факт берётся только из HTML сайта компании; нет факта = пустое поле.
- Перед персонализацией строка проверяется: домен почты не совпадает с сайтом, название компании не найдено на сайте, сайт не на русском и не на .ru → строка получает флаг и не персонализируется (`skipped_needs_review`).

## Что получилось

- Сбор: из 112 доменов адрес нашёлся у 64; после ручной чистки в базе 58 компаний, 48 из них с персонализацией. Исключены 6 (адрес не РФ, ящик для сообщений о коррупции и т.п.), причины в таблице.
- Персонализация в таблице состоит из двух частей: проверенный факт (колонка «Факт», цитата в evidence, ссылка на источник) и осторожный вывод, что это значит для привлечения клиентов (гипотеза, помечена словами «вероятно/похоже/повод»). Факты и цитаты взяты скриптом из HTML, формулировки я редактировал вручную с помощью ИИ. Новых фактов не добавлялось.
- Для 10 компаний факта нет: вместо выдуманного есть «запасной заход по сегменту» (общая фраза про сегмент, не факт о компании).
- Задача 4: в таблице заказчика данные сдвинуты между строками (3, 5, 6, 7), у Unimach неверное название («Tesid Equipment»), у Ункомтех чужие сайт и почта, большинство строк не из РФ. Прогон `personalize.py`: 3 строки ок (HNC, Искролайн, Техносфера), 8 пропущены с флагами (чужая почта, название не найдено на сайте, не РФ), 4 сайта не открылись. Часть строк я дополнительно сверил с сайтами вручную.

## Где застрял / ограничения

- Ключа API не было, поэтому LLM-режим персонализации написан, но не запускался. Режим без LLM даёт проверяемые, но шаблонные формулировки.
- Имена ЛПР: `enrich_names.py` нашёл имена у 32 из 58 компаний. После проверки в таблице 19 имён: 9 надёжных (страница руководства или публикация в прессе), 10 с пометкой «Проверить»; остальные отброшены как мусор или клиенты из кейсов. Проверка показала, что скрипт может брать устаревшие должности (Calltouch) и чужие имена (Softline), поэтому имена нужно сверять с источником. У остальных компаний имени нет.
- Email проверен только по MX домена, живость ящиков не проверена верификатором.
- У 10 компаний персонализации нет: найден только мусор или анонс без содержания.

## Цепочка писем и курс Polza Agency × DealRocket

Письма доработаны по урокам 3 и 4 мини-курса: первый вопрос про ответственного человека вместо прямого оффера, темы без кликбейта и со словами «компания» и проблемой, бесплатный разбор как лид-магнит, ротация приветствий через `{{random: …}}`, break-up с P.S. Число писем осталось 3 по условию задания (курс рекомендует 4 с интервалами 1→3→7→14). Пример работы в письме 2 взят из самого курса (бюро «Железно»), результатов я не указываю.
